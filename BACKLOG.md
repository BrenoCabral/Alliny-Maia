# Backlog

Fonte oficial do que fazer e em que ordem. O processo está em `agent-pipeline.md`.

- A ordem das linhas em "A fazer" é a ordem de prioridade. A próxima task é a primeira não marcada.
- Cada task aponta para o arquivo de definição e para a pasta que guarda os demais documentos dela.
- Ao concluir, o `dev-implementer` marca com X, acrescenta a data e move a linha para o topo de "Concluídas".
- Só o `pm` cria tasks e muda a ordem.
