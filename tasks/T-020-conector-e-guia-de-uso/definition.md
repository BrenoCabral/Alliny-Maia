# T-020 Conector no Claude e guia de uso

- Fase: 5. Claude
- Status: definida
- Depende de: T-019

## Objetivo

A Alliny usa o Claude no dia a dia para pensar sobre cada cliente, com o conector ligado e orientações prontas.

## Contexto

A integração só gera valor se for simples de usar para quem não é técnica.

## Escopo

- Passo a passo para adicionar o conector na conta da Alliny.
- Instruções de projeto para o Claude: papel, tom, como consultar a plataforma, o que não fazer.
- Guia curto de uso com exemplos de pedidos.
- Lista de cuidados de privacidade ao usar o conector.

## Fora do escopo

- Automação de tarefas agendadas.

## Critérios de aceite

- [ ] A Alliny conecta sozinha seguindo o guia.
